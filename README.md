# Автономний смарт-стелаж безкасового обслуговування (Smart Shelf Unit)

Навчальний проєкт з дисципліни **«Архітектури мультимедійних та смартсистем»** (Лабораторна робота 1).  
Кафедра програмного забезпечення комп'ютерних систем (ПЗКС), ФПМ, КПІ ім. Ігоря Сікорського.

---

## Предметна область та призначення системи
Проєкт присвячено проєктуванню архітектури автономного торговельного стелажа безкасового самообслуговування (концепція «Grab and Go» / Amazon Go). 

Система поєднує дві модальності даних:
1. **Мультимедійний потік:** Відео з оглядової камери стелажа (1080p, 25 fps) для трекінгу рук покупця та розпізнавання осередку товару.
2. **Сенсорний числовий потік:** Високочастотні відліки з тензометричних платформ (ваги) під кожною полицею (50 Гц).

На основі концепції **Sensor Fusion** система локально (на Edge-вузлі) зіставляє зміну ваги з просторовими координатами руху руки, формуючи віртуальний чек покупця та фіксуючи випадки пересорту товару.
